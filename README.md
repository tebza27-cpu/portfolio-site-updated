# Cybersecurity Operations Dashboard

## Overview
This project demonstrates a full penetration testing workflow conducted in a virtual lab environment.

## Workflow
- Network scanning using Nmap and Netcat
- Service enumeration and analysis
- Vulnerability identification
- Exploitation using Metasploit
- Root-level system access achieved

## Dashboard
The results were visualized using Power BI and embedded into a live portfolio website.

## Technologies Used
- Kali Linux
- Metasploit Framework
- Nmap & Netcat
- Power BI
- Flask (Python)
- HTML/CSS
